# fortlibrary

Community Quickfort blueprints for Dwarf Fortress, made with the
[Fortplanner grid editor](https://fortplanner.com) and browsable at
[blueprints.fortplanner.com](https://blueprints.fortplanner.com).

This repository holds the blueprint DATA only: one `.csv` per blueprint under `blueprints/`.
Every file is a normal Quickfort blueprint that downloads and runs as-is.

## Using a blueprint

Download the `.csv` (or use the Download / Copy buttons on the browse site) and run it with
DFHack's quickfort, or open it in the [editor](https://fortplanner.com) to inspect and adapt it.

## Sharing your own

Use the submission form on [blueprints.fortplanner.com](https://blueprints.fortplanner.com):
paste your blueprint straight from the editor. Accepted submissions are committed here
automatically.

## Metadata

Each blueprint carries its card metadata inside its own `#notes` section (title, author, tags,
df_version, description, and optionally `colors:` for author-picked preview tile colours), so the
file stays a valid, self-contained blueprint.
